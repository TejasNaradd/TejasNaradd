## 🚀  Things I've Built

<div align="center">

### 🏋️ Fitness Tracker — Microservices Application

**Java · Spring Boot · Kafka · Redis · Eureka · MongoDB · MySQL**

A Spring Boot microservices-based fitness tracker for managing users and activity data. Services communicate through Kafka, use Eureka for service discovery, and Redis for caching. The project also integrates the Gemini API to generate personalized fitness insights.

<br/>

### 🤖 AI Gmail Reply — Chrome Extension

**Java · Spring Boot · Spring WebFlux · WebClient · Gemini API**

An AI-powered Chrome extension that helps generate personalized Gmail replies in different writing tones. The backend uses Spring WebFlux and WebClient for non-blocking communication with the Gemini API.

<br/>

### 🎬 Movie Ticket Booking System

**Java · Struts 2 · Hibernate · MySQL · JSP · JSTL**

A full-stack movie ticket booking application with theatre and showtime browsing, seat booking, user sessions, and booking management.
